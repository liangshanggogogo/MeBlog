# 林间片刻

首页右侧的正交俯视小景，以浅绿树冠、暖色木屋、溪流和木桥构成安静的 2.5D 微缩风景。场景直接嵌入首页，使用透明画布融入全站纸色背景。

## 文件与调整位置

| 文件 | 内容 |
| --- | --- |
| `src/components/Landscape.astro` | 静态图片、画布、播放按钮、按需加载和减少动态效果偏好 |
| `src/scripts/landscape.js` | Three.js 场景、相机、几何体、灯光、交互、循环及资源清理 |
| `src/shaders/stream.vert.glsl` | 水面世界坐标 |
| `src/shaders/stream.frag.glsl` | GLSL 3 水色、波光、夜间颜色与点击涟漪 |
| `src/styles/global.css` | 首页布局、响应式尺寸、控件与主题 |
| `public/images/landscape/` | 从场景导出的日间、夜间静帧 |

相机使用正交投影；场景按固定随机种子生成，每次打开保持相同布局。树木、房屋、桥面等使用共享几何体和材质，草丛使用实例绘制。没有外部模型和纹理。

## 动画与交互

环境动画以 40 秒为完整周期，树冠、光斑、水纹、落叶、炊烟与萤火微光的周期均可整除 40 秒。落叶、炊烟在各自周期边界变为透明，循环时不会突然跳回起点。

鼠标在画布内移动时，相机缓慢产生小幅视差。点击溪流通过射线拾取水面位置，再将位置与时间传入着色器。键盘和触屏用户也可以使用“泛起涟漪”按钮。暂停后保留当前画面；暂停状态下主动触发涟漪只播放这次水波，不恢复环境动画。

深色模式沿用全站主题状态，降低日光亮度、调整植被与水色，并点亮窗户和少量萤火微光。

## 加载与性能

- 首先呈现响应式 WebP 静帧，三维代码只在首页风景接近可见区域时按需加载。
- 着色器使用 `compileAsync` 预编译，完成后切换到真实画布。
- 帧率上限 30 fps，像素比例上限 1.75；离开视口或标签页隐藏时停止循环。
- 暂停且没有交互时不持续提交绘制；页面离开时释放观察器、事件、几何体、材质及渲染器。
- 系统启用减少动态效果时不自动下载三维运行代码，显示对应主题静帧，可通过播放按钮主动开启。
- 缺少 WebGL2、初始化失败或 JavaScript 被禁用时保留静帧；图形上下文丢失时切回静帧，恢复后继续绘制。

## 更新静帧

修改场景构图或配色后，同步更新日间和夜间图片。让画布在正面默认视角暂停，以 1000 × 840 的透明背景分别截图，然后导出同名 WebP 和 500 × 420 的小尺寸版本。不要对整页截图，否则会把纸色背景一起写入图片。

## 验证

构建运行 `npm run build`。浏览器确认昼夜两种主题、375px 手机和桌面布局、自动播放、暂停、涟漪、离开视口后停止，以及系统减少动态效果下的手动播放。可通过禁用 WebGL2 检查静帧后备显示，并通过 `WEBGL_lose_context` 扩展验证上下文丢失与恢复。
